# Store listing copy

Focus keyword: **Pakistan Live TV Channels Free**

It appears in the title, the short description and the opening line of the
long description — the three places Play actually weights. After that it is
used where it reads naturally and nowhere else, because Play's Metadata
policy treats repeated or irrelevant keywords as grounds for rejection, and a
listing that trips it does not rank at all.

---

## App name (30 max)
```
Arslan TV: Pakistan Live TV
```
27 characters. Keeps the brand and puts the keyword where Play weights it
hardest. If you would rather drop the brand entirely, `Pakistan Live TV
Channels` is 25 and ranks slightly better — at the cost of having no name of
your own to build on later.

## Short description (80 max)
```
Watch Pakistan live TV channels free — news, drama, cartoons on TV or phone.
```
76 characters.

## Still yours to fill in
- **Privacy policy URL** — required, and the page must be live before review.
- **Contact email** — shown publicly on the listing.
- **Screenshots** — in `screenshots/`. Play wants at least two phone shots;
  add the TV set against the Android TV form factor if you tick that box.

## One honesty check before you paste

The long description names specific broadcasters. That is accurate and it
helps the listing rank, but it is also exactly what a reviewer reads when
deciding whether you have the rights to carry those channels. Name them only
if you are comfortable defending it at review.
